# AI has deep memory now 👉 how to use it

Natalie MacNeil opisuje, jak pamięć stała się centralnym elementem działania głównych systemów AI — Anthropic ujednolicił pamięć Claude między chatem a Cowork, a OpenAI wprowadził "dreaming", proces w tle syntetyzujący wiedzę o użytkowniku między rozmowami. Autorka przeplata to refleksją nad mitem o Talosie, brązowym strażniku z mitologii minojskiej, jako metaforą AI, które dobrze pilnuje granic, ale nie powinno decydować o tym, co jest święte. Kluczowa część newslettera to gotowy prompt do przeprowadzenia "audytu pamięci" — systematycznego przeglądu tego, co dany model AI faktycznie wie (lub zakłada) o biznesie użytkownika.

## Frameworki i metody
- **Audyt pamięci AI** — comiesięczny przegląd tego, co [[ChatGPT]] lub [[Claude]] "wie" o firmie użytkownika: model, oferta, klienci, cele, wartości, zespół, narzędzia. Wyniki dzielone na cztery kategorie — trwałe fundamenty, aktywny kontekst, informacje przestarzałe/sprzeczne, założenia wywnioskowane przez model — z rekomendacją działania (zachować / zaktualizować / usunąć / przenieść) dla każdej pozycji.

## Wnioski
- Ustawienia pamięci w [[Claude]] (Settings → Memory → "Generate memory from chats") organizują wiedzę w edytowalne pliki tematyczne i domyślnie wykluczają tematy wrażliwe (zdrowie, przekonania, polityka) — trzeba je świadomie włączyć.
- [[ChatGPT]] aktualizuje kontekst automatycznie w tle ("dreaming"), ale też przyjmuje jawne instrukcje typu "zapamiętaj to jako trwałą preferencję" — warto testować oba mechanizmy pamięci u klientów wdrażających AI.
- Regularny audyt pamięci to praktyczne narzędzie do higieny danych w konsultingu AI — pozwala wychwycić błędne założenia modelu, zanim wpłyną na jakość rekomendacji czy treści tworzonych dla klienta.

## Cytat
> Niech pilnuje peryferii, logistyki, powtarzalności, niestrudzonej obserwacji, ale w centrum decyzje o tym, co jest święte, co warte ryzyka i kim się stajemy, muszą pozostać nasze.

## Zastosowanie
Prompt do audytu pamięci można od razu wykorzystać we własnej pracy z Claude i ChatGPT oraz zaproponować klientom NGO jako proste ćwiczenie higieny danych przy wdrażaniu AI. Ramka "co jawne / co z pamięci / co wywnioskowane" przydaje się też jako argument w rozmowach o transparentności i kontroli nad AI w sektorze społecznym.
